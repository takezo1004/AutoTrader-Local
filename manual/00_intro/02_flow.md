# 0-2 ご利用開始までの流れ

※ 初めてご利用になる場合は、この順番どおりに進めてください。手順を飛ばすと動作しません。

※ ①②は初回のみ行います。③以降は毎日の操作です。

## ① 事前にご用意いただくもの

| 項目 | 内容 |
|---|---|
| **kabuステーション** | auカブコム証券の取引ソフトです。API を使用する設定にしておきます（ブリッジのマニュアル 1-1） |
| **ブリッジ** | 開発キットで AutoTrader Bridge を作成し、インストールして、パスフレーズまで設定を済ませておきます（ブリッジのマニュアル 1-1〜1-9） |
| **戦略** | 配布された戦略パッケージです（ZIP または解凍済みフォルダ） |
| **履歴データ** | 直近 6 ヶ月ぶんの 15 分足です。[2-3 履歴データの入手先](../02_data/03_sources.md) |

## ② 初回のみ行う設定

1. [1-1 起動と終了](../01_setup/01_startup.md) … ダッシュボードを起動します。
2. [1-3 設定画面](../01_setup/03_settings.md) … ブリッジの場所（exe パス）を設定します。
3. [2-2 履歴データを取り込む](../02_data/02_import.md) … 6 ヶ月ぶんのデータを取り込みます。
4. [2-5 市場カレンダー](../02_data/05_calendar.md) … 祝日取引のカレンダーを取得します。
5. [3-1 戦略を登録する](../03_strategy/01_register.md) … 使用する戦略を登録します。

## ③ 毎日の操作

1. **kabuステーション**を起動し、ログインします。
2. **ダッシュボード**を起動します。記録が始まり、AutoTrader Bridge も同時に起動します。
3. ブリッジが起動していない場合は、**［▶ 起動］**を押します。
4. 発注する戦略の**「有効」に ✓** を入れます。
5. 取引終了後に[停止](../04_run/03_stop.md)します。

詳しくは [4-1 運用の流れ](../04_run/01_flow.md) をご覧ください。
