# 3-6 登録を解除する

※ 解除しても、**戦略のフォルダそのものは消えません**（`strategies/` に残ります）。

※ 解除すると、その戦略は**動かなくなり、記録も残らなくなります**。

※ **取引記録を消すかどうかは、そのとき確認されます。**

## 手順

1. ⑤の一覧で、外したい戦略の行を選びます。
2. **［− 削除］**（③）を押します。
3. 「**「〇〇」を登録解除しますか？（実体は消えません）**」と出ますので、よろしければ **［はい］**。
4. 続けて「**この戦略の取引記録も一緒に削除しますか？**」と確認されます。
   - **［いいえ］** … 記録は残ります（あとで [📒 取引記録](../04_run/04_records.md) で見られます）。
   - **［はい］** … その戦略の取引記録が消えます。**元に戻せません。**

## 「注文を止めたいだけ」なら解除しないでください

**注文を止めるだけなら、「有効」の ✓ を外すだけで足ります**（[4-2](../04_run/02_enable.md)）。
そのほうが記録は残り続けるので、あとから見返せます。

| やりたいこと | すること |
|---|---|
| **今日は注文したくない** | ⑤の「有効」の ✓ を外す |
| **もう使わない** | ［− 削除］で登録解除 |
| **入れ直したい** | 登録解除 → もう一度[登録](01_register.md) |

## 解除したあと

- ⑤の一覧から消えます。
- `strategies/<フォルダ名>/` は残っているので、**同じフォルダを選べばすぐ登録し直せます**。
- パラメータの変更内容も、そのフォルダに残ったままです。
