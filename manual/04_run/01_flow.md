# 4-1 運用の流れ

※ **オートトレードの起動ボタン・停止ボタンはありません。**ダッシュボードを起動した時点で
   自動運用（記録）が始まり、**発注するかどうかは戦略ごとの「有効」だけ**で決まります。

※ **市場が閉じている時間帯は発注されません。**

※ 始める前に [1-5 取引を始める前の確認](../01_setup/05_check.md) を必ず行ってください。

## 朝の手順

1. **kabuステーションを起動**してログインします。
2. **ダッシュボードを起動**します（[1-1](../01_setup/01_startup.md)）。
   - ログに「**自動運用 準備完了**」と出るまで待ちます。
   - 画面いちばん上に**赤い帯が出ていないこと**を確認します。
3. ②の**カブ**ランプが緑になっていることを確認します。
4. **［▶ 起動］**（④）でブリッジを起動します。**ブリッジ**ランプが緑になります。
5. しばらくして **feed** ランプが緑になれば、値段が届いています。
6. **ブリッジ側の自動売買スイッチを ON** にします（ブリッジのマニュアル 2-2）。
7. 発注する戦略の **「有効」に ✓** を入れます（[4-2](02_enable.md)）。
   **オートトレード**ランプが緑になります。

これで運用中です。あとは確定した足ごとに、戦略が判断してブリッジへ発注します。

## 稼働中に確認する箇所

| 場所 | 何が分かるか |
|---|---|
| ⑤の **建玉** | いま何枚持っているか |
| ⑤の **直近シグナル** | 最後に何が発火したか |
| ⑦の **ログ** | 足の確定・シグナル・送信結果・エラー |
| 画面上部の**赤い帯** | 出ていたら記録が止まっています（[6-2](../06_trouble/02_record_stop.md)） |

## 稼働中の戦略の追加・変更

運用中でも、**戦略の追加・パラメータの変更・登録の編集ができます**。
**ほかの戦略は止まりません**（[3-1](../03_strategy/01_register.md)）。

## 取引終了後

[4-3 停止する](03_stop.md) をご覧ください。

## 停止後に再開した場合

**持っている建玉と、その利食い・損切りの状態は、起動時に過去の足から作り直されます。**
そのため、**持ち越した建玉の返済も、再開後にきちんと発火します**。

- 作り直しをしている間（ウォームアップ中）の発火は、**注文もしませんし、記録にも残しません**。
- 作り直しが終わったあと、**新しい足から**注文と記録が再開します。
- ただし、**止めている間に起きたはずの売買**は、そもそも起きなかったものとして扱われます。
  実際の建玉との食い違いが心配なときは、**ブリッジ側の建玉一覧**で確かめてください。
