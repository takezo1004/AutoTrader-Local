# 5-1 状態ランプ（LED）とログの見方

※ **4 つのランプは、それぞれ別のことを表しています。**まとめて 1 つの状態ではありません。

※ 更新は **3 秒ごと**です。押した直後に色が変わらなくても、少し待ってください。

## 4 つのランプ（②）

| ランプ | 緑（点灯）の意味 | 灰のときに見るところ |
|---|---|---|
| **カブ** | kabuステーションが起動し、API が応答している | kabuステーションの起動・ログイン・API 設定 |
| **ブリッジ** | ブリッジが動いている | ［▶ 起動］を押す・[1-4](../01_setup/04_bridge.md) |
| **オートトレード** | **「有効」の戦略が 1 つ以上ある**（注文の経路が開いている） | ⑤の「有効」に ✓ を入れる |
| **feed** | **ブリッジから値段（tick）が届いている** | [6-4](../06_trouble/04_feed.md) |

> **オートトレードのランプが緑＝「注文されうる状態」**という意味です。
> 実際に注文されるには、ブリッジも動いていて、戦略が発火する必要があります。

> **記録は、ランプや「有効」に関係なく常に行われます**（[4-4](../04_run/04_records.md)）。

## ログ（⑦）の色

| 色 | 内容 |
|---|---|
| **緑** | ブリッジへの送信・取引の記録 |
| **黄** | 記録だけ（「有効」でない戦略の発火） |
| **赤** | エラー・要更新の案内 |
| **白・灰** | 起動や接続などの経過 |

## ログに出る足について

- **ろうそく足は、セッションの最初と最後だけ**を表示します
  （日中の 8:45 と 15:45、夜間の 17:00 と 6:00）。
- **途中の足は表示しません**が、**ファイルにはすべて残ります**（[5-2](02_files.md)）。
  画面が流れて読めなくなるのを避けるためです。

## 取引の記録が出る行

発火すると、次の形で 1 行出ます。

```
[記録] <ショートネーム> <新規/決済> <方向>×<数量> @<価格> <損益> <理由> [本番/仮想]
```

**［本番］＝「有効」で注文したもの、［仮想］＝記録だけのもの**です。

## 記録停止中の赤い帯

画面のいちばん上に **「⚠ 記録停止中: …」** と赤い帯が出ることがあります。
**正常なときは何も出ません**（＝何も出ていないことが、記録できている証拠です）。
出たときは [6-2 記録が止まる](../06_trouble/02_record_stop.md) をご覧ください。
