# 5-3 ブリッジへ送る内容

※ **ふだんの操作では、この節を読む必要はありません。**何が送られているかを知りたい方向けです。

※ 送る内容の決まりは**ブリッジ側が正本**です（`N225BrokerBridge/docs/webhook-api-spec.md`・**版 1.0.0**）。
   このページは**その要点を利用者向けに書いたもの**で、細かい形は正本をご覧ください。

※ 送り先は設定画面の「ブリッジ URL」です（既定 `http://localhost:8001/webhook`）。

## いつ送られるか

**「有効」に ✓ が入っている戦略が発火したとき**だけです（[4-2](../04_run/02_enable.md)）。
「有効」でない戦略は、**送らずに記録だけ**します。

## 何を送っているか

| 内容 | 説明 |
|---|---|
| **パスフレーズ** | ブリッジと合わせる合言葉（[1-3](../01_setup/03_settings.md)） |
| **戦略名（ショートネーム）と足（インターバル）** | ブリッジはこの**組み合わせで戦略を見分けます**（[3-2](../03_strategy/02_edit.md)） |
| **売買の内容** | 買う／売る・枚数・建玉がどう変わるか（新規・返済・分割返済・ドテン） |
| **値段** | **実際に約定した値段**（新規なら建値、返済なら返済した値段） |
| **足の情報** | その足の始値・高値・安値・終値・出来高と時刻 |

**形は TradingView のアラート本文と同じにそろえてあります。**
ローカル版と TradingView 版のどちらから送っても、ブリッジは同じように受け取れます。

## 発注する銘柄について（現状の決まり）

- ローカル版のろうそく足は、**日経225ミニ**の値段から作っています。
- **実際にどの銘柄で発注するかは、ブリッジ側で選んでいる銘柄**で決まります。
  送られた銘柄名は、発注の判断には使われていません。
- そのため、**ブリッジ側をマイクロにしておけば、マイクロで約定します**。
- 「足とシグナルはミニ／発注は別」という分け方になります（[2-3](../02_data/03_sources.md)）。

## 送れなかったとき

- ⑦のログに**赤**で結果が出ます。
- よくある原因は、**ブリッジが起動していない**・**パスフレーズが合っていない**・
  **ブリッジ側にその戦略が登録されていない**の 3 つです。
- [6-3 注文されない](../06_trouble/03_no_order.md) をご覧ください。
