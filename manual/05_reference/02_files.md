# 5-2 ファイルの保存場所

※ すべて **N225LocalEngine のフォルダの中**にあります。ほかの場所には作りません。

※ **バックアップを取るなら `app/state` と `data` の 2 つ**です。

※ 手で書き換えないでください（壊れると起動できなくなることがあります）。

## 設定と状態（`app/state`）

| ファイル | 中身 | 消えると |
|---|---|---|
| `settings.json` | ブリッジ URL・exe パス・データの場所・テーマ・文字サイズ | 設定をやり直します |
| `registered.json` | 登録した戦略の一覧（ショートネーム・インターバル・有効） | 登録をやり直します |
| `trade_log.jsonl` | **取引記録**（[4-4](../04_run/04_records.md)） | 記録が消えます |
| `positions/` | 建玉の控え（診断用） | 影響ありません |

> **パスフレーズはファイルに保存されません。**起動のたびにブリッジから取り込みます
> （[1-3](../01_setup/03_settings.md)）。

## 市場データ（`data`）

| 場所 | 中身 |
|---|---|
| `ohlc_live.parquet` | **蓄積ストア**（ろうそく足・直近 6 ヶ月）（[2-1](../02_data/01_store.md)） |
| `csv_import/` | 取り込む履歴ファイルの置き場所。古い CSV は `_archive/` へ自動退避 |
| `market_Calendar.csv` | **市場カレンダー**（[2-5](../02_data/05_calendar.md)）。人が読める形式です |
| `history/` | 退避された取引記録（四半期ごと）（[4-5](../04_run/05_archive.md)） |
| `logs/` | 稼働ログ（下記） |

## 稼働ログ（`data/logs`）

- ファイル名は **`localengine_YYYY-MM-DD.log`**（1 日 1 ファイル）です。
- **画面のログ欄は閉じると消えますが、このファイルは残ります。**
- あとから経緯を追いたいとき、うまく動かなかった原因を調べたいときに開いてください。

## 戦略（`strategies`）

登録した戦略が、**フォルダごと**入っています。
パラメータの変更内容も、それぞれの `config.json` に保存されます。
登録を解除しても、**このフォルダは残ります**（[3-6](../03_strategy/06_remove.md)）。

## バックアップの推奨

| 頻度 | 取るもの |
|---|---|
| 設定を変えたとき | `app/state`（設定・登録・取引記録） |
| ときどき | `strategies`（パラメータを調整した戦略） |
| 不要 | `data/ohlc_live.parquet`（取り込み直せます） |
