# 用語集

このマニュアルに出てくる言葉を、出てくる順に近い形で並べています。

## システムの部品

| 用語 | 意味 |
|---|---|
| **ローカル版（N225LocalEngine）** | 本製品。お使いのパソコンの中でろうそく足を作り、戦略を動かします |
| **ダッシュボード** | ローカル版の画面。登録・調整・確認をすべてここで行います |
| **ブリッジ（N225BrokerBridge）** | 別製品。シグナルを受け取って実際に発注します |
| **kabuステーション** | auカブコム証券の取引ソフト。ブリッジがこれを通して注文します |
| **TradingView 版** | 同じブリッジを使う別製品。足づくりを TradingView 側で行います |

## 売買のことば

| 用語 | 意味 |
|---|---|
| **シグナル** | 戦略が出した「買う・売る・返済する」の合図 |
| **発火** | 戦略がシグナルを出すこと |
| **新規** | 建玉を新しく持つこと |
| **返済（決済）** | 持っている建玉を返すこと |
| **建玉** | いま持っている数量 |
| **約定** | 売買が成立すること |
| **ドテン** | 買いから売りへ（またはその逆へ）一度に転換すること |
| **分割返済** | 持っている枚数を何回かに分けて返すこと |
| **レグ** | 1 回の返済の単位。分割すると 1 回の建玉から複数のレグが出ます |

## データのことば

| 用語 | 意味 |
|---|---|
| **ろうそく足** | 一定時間の値動きを 1 本にまとめたもの。本製品は 15 分足を使います |
| **確定足** | 15 分が終わって確定した足。戦略はこの足ごとに判断します |
| **tick** | 1 件ずつの値段。ブリッジから届き、これを集めて足を作ります |
| **蓄積ストア** | ろうそく足を貯めるファイル（`data/ohlc_live.parquet`） |
| **6 ヶ月ローリング** | 直近 6 ヶ月だけを残し、古いものを自動で切り詰める仕組み |
| **板寄せ特別足** | 引けの値段で立つ、その日最後の足（15:45／6:00） |
| **セッション** | 取引の時間帯。日中（8:45〜15:45）と夜間（17:00〜翌 6:00） |

## 動作のことば

| 用語 | 意味 |
|---|---|
| **ウォームアップ（warmup）** | 起動直後に過去の足を流し込み、指標と建玉の状態を整えること |
| **自動運用** | ダッシュボード起動と同時に始まる、足づくりと記録の動作 |
| **有効** | その戦略の発火をブリッジへ送るかどうかのスイッチ |
| **本番／仮想** | 記録上の区別。本番＝有効で注文したもの／仮想＝記録だけのもの |
| **記録停止中** | 発火が記録できない状態。画面上部に赤い帯が出ます |

## 設定のことば

| 用語 | 意味 |
|---|---|
| **パスフレーズ** | ブリッジと合わせる合言葉。ブリッジ側が正で、エンジン全体で 1 つ |
| **ショートネーム** | ブリッジへ送る戦略名 |
| **インターバル** | 何分足で動かすか（15＝15 分足） |
| **Webhook** | ブリッジへシグナルを届けるしくみ（ポート 8001） |

## 成績のことば

| 用語 | 意味 |
|---|---|
| **バックテスト** | 過去のデータで戦略を試し、成績を計算すること |
| **プロフィットファクター（PF）** | 総利益 ÷ 総損失。1 を超えていれば勝ち越し |
| **最大DD（ドローダウン）** | 期間中でいちばん落ち込んだときの金額 |
| **コスト感度** | 手数料などのコストを増やしても成績が保てるかの確認 |
| **損益曲線** | 損益の積み上がりを線で表したもの |
| **自動調整（再最適化）** | 直近のデータから良い設定値を探して提案する機能 |
